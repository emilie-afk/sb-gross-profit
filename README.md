# SB Gross Profit

A recurring gross profit reporting pipeline and review app. It validates uploaded order and fulfillment data and publishes a report when the inputs are ready. Reprocessing unchanged inputs does not create a duplicate published report.

## Features

- Review revenue, costs, and gross profit by reporting period.
- Track changes over time and compare what-if scenarios side by side.
- Supply profit and cost figures to the [Marketing Dashboard](https://github.com/emilie-afk/sb-marketing-dashboard).
